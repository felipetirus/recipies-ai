# Recipes AI 🍳

An AI-powered recipe browser with interactive filtering and nutrition analysis.

## Features
- 🔍 Search by recipe name or ingredients
- 🍽️ Filter by meal type (breakfast, lunch, dinner)
- 📊 Nutrition breakdown with radar charts
- 📱 Responsive design (works on mobile & desktop)
- 🌙 Dark mode support

## View Online
Open `recipes.html` in your browser or visit:
